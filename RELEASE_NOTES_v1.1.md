## Cyber30 v1.1 (tester preview)

Learn to think, speak and act like a security professional in 30 days: bite-sized lessons, hands-on Kali labs, quizzes, flashcards and live threat news, plus 4 bonus lessons on AI, zero-days and reverse engineering.

### Install on Android
1. Download **Cyber30.apk** below on your phone.
2. Open it and allow **Install unknown apps** for your browser when Android asks.
3. Open Cyber30 → **Me** → **Continue with Google** to sync your progress across devices.

### Install on Kali / Linux
```bash
git clone https://github.com/nightlybit/cyber30 && cd cyber30 && ./install.sh
```

### Please send feedback
Use **Me → Send feedback** in the app, or tap **Rate it** after finishing a day. Bugs, confusing lessons and ideas are all welcome.

### Notes
- Lessons work offline; sync happens when you're online.
- Days 14–18 link to free outside courses (PortSwigger Web Security Academy, OWASP).
- Practise only on systems you own or have permission to test.
